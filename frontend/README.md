# BorrowBetter — Frontend

رابط کاربری راست‌چین BorrowBetter با **Vanilla JavaScript + Vite**؛ بدون فریم‌ورک، بدون وابستگی رانتایم.
قرارداد API دقیقاً همان `TEAM-SPEC` است: `snake_case`، پاکت `{data, meta}` / `{error}` و زمان‌ها UTC.

---

## اجرا

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173
```

- Node 20 یا بالاتر.
- پورت ۵۱۷۳ به‌صورت `strictPort` قفل است تا با `CORS_ORIGINS` بک‌اند بخواند.
- برای دیدن رابط بدون بک‌اند: `http://localhost:5173/?mock=1`

| دستور | کار |
|---|---|
| `npm run dev` | سرور توسعه |
| `npm run build` | بیلد تولید در `dist/` |
| `npm run preview` | سرو بیلد روی ۴۱۷۳ |
| `npm test` | تست واحد توابع پایه (زمان، تقویم، اعتبارسنجی، مسیر) |

> اگر از pnpm استفاده می‌کنی و پیام `Ignored build scripts: esbuild` دیدی، یک بار `pnpm approve-builds` را بزن.

## حالت نمایشی (Mock)

با `?mock=1` یک API شبیه‌سازی‌شده داخل مرورگر فعال می‌شود. این حالت:

- همان قرارداد و همان کدهای خطا را برمی‌گرداند (شامل `409 SLOT_CONFLICT` با ۳ پیشنهاد).
- داده را در `localStorage` نگه می‌دارد و توکن را در `sessionStorage` — پس **دو تب = دو کاربر**.
- با `?mock=0` خاموش می‌شود و دیگر روشن نمی‌ماند.

| کاربر | ایمیل | رمز | نقش |
|---|---|---|---|
| ثنا | `sana@demo.ir` | `Demo1234!` | صاحب چند وسیله |
| اسرا | `asra@demo.ir` | `Demo1234!` | متقاضی |
| شقایق | `shaghayegh@demo.ir` | `Demo1234!` | صاحب دوربین |

بازنشانی داده در کنسول: `window.__bb.resetMock()` — یا `localStorage.removeItem('bb_mock_db_v1')` و رفرش.

### سناریوی ۴۰۹ در دو تب

1. تب ۱: با `asra@demo.ir` وارد شو، وسیلهٔ «چادر مسافرتی ۴ نفره» را برای فردا ۱۰–۱۴ درخواست کن.
2. تب ۲: با `sana@demo.ir` وارد شو و همان درخواست را تأیید کن.
3. تب ۱: همان بازه را دوباره بزن → پیام فارسی + بازهٔ متداخل + چیپ‌های پیشنهاد.

## اتصال به بک‌اند

```bash
cp .env.example .env
# VITE_API_BASE=http://localhost:8000/api/v1
```

- بک‌اند باید `http://localhost:5173` را در `CORS_ORIGINS` داشته باشد.
- اگر `?mock=1` در URL نباشد، همهٔ درخواست‌ها واقعی‌اند.
- نام فیلدها در کد عیناً `snake_case` است؛ هیچ لایهٔ تبدیل وجود ندارد.

قواعد کلیدی که در کد رعایت شده:

- `Authorization: Bearer <token>` و پاکت خطا: `{ error: { code, message, details } }`.
- هر `401` → پاک‌کردن نشست، اعلان فارسی و هدایت به `#/login?redirect=...`.
- `409 SLOT_CONFLICT` → نمایش پنل تداخل، بازهٔ درخواستی، بازه‌های متداخل و چیپ‌های پیشنهاد (بدون `alert`).
- قیمت با فرمول سند: `price_per_day × max(1, ceil(ساعت / ۲۴))`.

## ساختار

```
frontend/
├─ index.html
├─ vite.config.js          # base: './' برای استقرار در زیرمسیر
├─ .env.example
└─ src/
   ├─ main.js              # پوسته، هدر/فوتر، bootstrap
   ├─ router.js            # روتینگ هش + گارد احراز هویت + chunk تنبل
   ├─ constants.js         # enumها، برچسب فارسی، رنگ وضعیت
   ├─ api/
   │  ├─ client.js         # پوشش fetch، پاکت، ApiError، ۴۰۱
   │  ├─ endpoints.js      # تمام اندپوینت‌های §۷
   │  └─ mock/             # دیتابیس و مسیرهای شبیه‌سازی
   ├─ store/auth.js        # توکن/کاربر در sessionStorage
   ├─ lib/                 # html (escape)، format، datetime، jalali، validate، query، icons
   ├─ components/          # هدر، فوتر، کارت‌ها، تقویم، مودال، اعلان، …
   ├─ pages/               # کاتالوگ، جزئیات، فرم وسیله، داشبوردها، ورود/ثبت‌نام، ۴۰۴
   └─ styles/              # tokens، components، pages
```

### مسیرها

| مسیر | صفحه |
|---|---|
| `#/` | خانه + کاتالوگ |
| `#/items` | همهٔ وسایل |
| `#/items/{id}` | جزئیات و رزرو |
| `#/items/new` / `#/items/{id}/edit` | ثبت/ویرایش (نیازمند ورود) |
| `#/login` / `#/register` | ورود و ثبت‌نام |
| `#/my/items` | داشبورد صاحب وسیله |
| `#/my/requests` | درخواست‌های من (متقاضی/صاحب وسیله) |
| `#/ai` | «به‌زودی» — AI خارج از محدودهٔ این نسخه |

## تصمیم‌های فنی

| موضوع | تصمیم |
|---|---|
| روتینگ | `#/...` با پارامتر و کوئری؛ هر صفحه یک chunk جدا (`import()`) |
| رندر | template string + `html` tag که همهٔ مقادیر را escape می‌کند |
| تقویم | جلالی سفارشی، محاسبه در UTC و تبدیل با آفست ثابت تهران `+03:30` |
| تاریخ ورودی | همیشه تبدیل به UTC ISO؛ نمایش با `Intl` و `Asia/Tehran` |
| انیمیشن | ورود صفحه، کارت‌های پله‌ای، هاور، اسکلتون، توست و مودال — با احترام به `prefers-reduced-motion` |
| دسترس‌پذیری | فوکوس پس از تغییر مسیر، تلهٔ فوکوس مودال، `aria-live` برای لیست/توست، کنتراست ۴.۵:۱ |
| فونت | Vazirmatn لوکال (OFL) — بدون CDN |

## دامنهٔ این نسخه

- AI پیاده‌سازی نشده؛ مسیر `#/ai` صفحهٔ «به‌زودی» دارد (تصمیم D9).
- «نشان‌کردن» (favorite) حذف شد چون اندپوینتی در قرارداد ندارد.
- آپلود تصویر نداریم؛ `image_url` متنی است. تصاویر نمونه در `public/img/` هستند و mock به آن‌ها وصل است؛ اگر `image_url` خالی یا خراب باشد، آیکون دسته نمایش داده می‌شود.
- فیلتر تاریخ در کاتالوگ به‌صورت API آماده است اما در UI این نسخه نمایش داده نمی‌شود.

## استقرار

```bash
npm run build
```

`dist/` را روی هر هاست استاتیک بگذار. `base: './'` است، پس روی GitHub Pages و زیرمسیرها هم کار می‌کند.
